输赢报告资料

定义:

这份报告显示所有会员和代理每场赛事的输赢资料。您可以选择所需的日期然后点击提交按钮。


图 4.1
用词注解:
  • 投注额: 总投注数额。
  • 投注类别: 被选定进行投注的投注类别。
  • 会员输赢: 会员输赢的数额。
  • 会员佣金: 会员从代理处得到的佣金数额。
  • 会员总和: 会员包括佣金的总输赢数额。
  • 代理输赢: 代理基于占成数的输赢数额。
  • 代理佣金: 扣除会员佣金后, 代理收到或支付予上线的佣金数额。
  • 代理总和: 代理包括佣金的总输赢数额。
  • 公司佣金: 代理从上线处得到的佣金数额.
  • 公司总和: 代理需支付予或从上线处接收到的总数额。
如何理解报告:

在这份报告中, 会员投注额 = 100, 赔率 = 0.66, 会员折扣 = 0.2%, 代理折扣 = 0.2%, 代理占成数 = 30%及会员赢得此投注。根据赛事FC Tokyo -vs- Jubilo Iwata 作为例子以理解如何计算此报告: (图4.1中, 第一行)。

  • 会员输赢 = 投注额 * 赔率 = 100 * 0.66 = 66.
  • 会员佣金 = 投注额 * 会员折扣 = 100 * 0.2% = 0.2
  • 会员总和 = 会员输赢 + 会员佣金 = 66 + 0.2 = 66.2
  • 代理输赢 = -(会员输赢 * 代理占成数) = -66 * 30% = -19.8
  • 代理佣金 = (投注额 * (投注额 * 代理折扣 * 上线占成数) - 会员佣金 = (100 * 0.2%*( 100% - 30%)) - 0.2 = -0.06
  • 代理总和 = 代理输赢 + 代理佣金 = -19.8 - 0.06 = -19.86
  • 公司佣金 = 投注额 * 代理折扣 * 上线占成数 = 100 * 0.2% * (1-30%) = 0.14
  • 公司总和 = -(会员总和 + 代理总和) = -(66.2 - 19.86) = -46.34

注: 这只是一个简单的例子来指导您如何计算单一投注的输赢数额。在现实中, 一场赛事可能包含许多投注所以我们必须计算每个投注的输赢及佣金, 然后总计所有输赢的数额。
