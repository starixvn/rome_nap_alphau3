会员输赢

定义:

这份报告显示所有必要的信息, 以帮助代理清楚了解个别会员在特定日期里的输赢。

当我们开启 "会员输赢", 页面会显示今日与昨日的个别运动类型的赛事场数, 当中包括 "成绩已输入场数" 和 "成绩还没输入场数" (图1.1)。

  • 成绩已输入场数: 赛事以输入成绩之总数.
  • 成績已輸入場數: 賽事以輸入成績之總數.

图 1.1

在 从 和 到 选择日期, 然后点击 "提交" 以查阅指定日期的输赢报告 (图1.2)。


图1.2

用词注解:

  • 投注额: 总投注数额。
  • 会员输赢: 会员输赢的数额。
  • 会员佣金: 会员从代理处得到的佣金数额。
  • 会员总和: 会员包括佣金的总输赢数额。
  • 代理输赢: 代理基于占成数的输赢数额。
  • 代理佣金: 扣除会员佣金后, 代理收到或支付予上线的佣金数额。
  • 代理总和: 代理包括佣金的总输赢数额。
  • 公司: 代理需支付予或从上线处接收到的总数额。
如何理解报告:

在这份报告中, 代理获取占成数30%, 代理折扣为0.2%及会员折扣为0.2%。为计算输赢, 我们必须点击用户名 (例如: member01), 进入会员投注列表页, 并显示每次投注之细节。


图1.3

现在, 例子将告诉您如何计算会员该投注单的输赢。在现实中, 我们必须计算每张投注单的输赢及佣金, 才能获得代理、会员的输赢总计。

如图1.2所示, 让我们根据member01计算代理的输赢, 假设member01只有一张投注单。

  • 会员输赢 = 投注额 * 赔率 = 100 * 0.66 = 66
  • 会员佣金 = 投注额 * 会员折扣 = 100 * 0.2% = 0.2
  • 会员总和 = 会员输赢 + 会员佣金 = 66 + 0.2 = 66.2
  • 代理输赢 = -会员输赢 * 代理占成 = -66 * 30% = -19.8
  • 代理佣金 = (投注额 * 代理折扣 * 上线占成) - 会员佣金
                  = [100 * 0.2% * (100 % - 30%)] – 0.2 = 0.14 – 0.2 = -0.06
  • 代理总和 = 代理输赢 + 代理佣金 = -19.8 – 0.06 = -19.86
  • 公司 = -(会员总和+代理总和) = -(66.2 – 19.86) = -46.34
