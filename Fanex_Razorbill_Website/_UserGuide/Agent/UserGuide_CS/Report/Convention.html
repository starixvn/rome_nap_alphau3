Conventions:

1. Date range selection

Most of reports contain the following control for date range (selection)


figure 1

[1] From date: state the start date for the report.
[2] To date: state the end date for the report.
[3] Current date: shortcut button to view current report.
[4] Yesterday date: shortcut button to view yesterday report.

To view the report, specify the desired date then click Submit button.

2. Win/Loss, Commission, Total number

  • Positive: indicates a winning amount or the one that the number owner can get from down-line or upline.
  • Negative: indicates a losing amount or the one that the number owner needs to pay to down-line or upline.

3. Export to excel

If the Excel icon appears at the top right most of the screen, click it to export the report into the excel file.

4. Down/upline

  • Down-line: account(s) belong to the mentioned account.
  • upline: parent account of the mentioned account
