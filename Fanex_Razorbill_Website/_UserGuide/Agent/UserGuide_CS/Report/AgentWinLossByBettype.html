投注类别输赢

定义:

这份报告显示会员总投注额, 会员输赢, 代理输赢, 及代理在一段时间内根据公司在每场投注的输赢必须支付予或从上线处接收到的数额。


图 5.1

用词注解:

  • 投注额: 会员根据投注类别的总投注额。
  • 会员输赢: 会员根据投注类别的输赢数额。
  • 会员佣金: 会员从代理处得到的佣金数额。
  • 会员总和: 会员包括佣金的总输赢数额。
  • 代理输赢: 代理基于占成数的输赢数额。
  • 代理佣金: 扣除会员佣金后, 代理收到或支付予上线的佣金数额。
  • 代理总和: 代理包括佣金的总输赢数额。
  • 公司: 代理需支付予或从上线处接收到的总数额。
如何理解报告:

从上图中, 我们可以告诉大家会员投注 1,500 于让球盘及大小盘的投注类别,共赢得 384, 代理输 115.2 及可从上线处得到 268.80 以补偿其支付于会员的数额。
