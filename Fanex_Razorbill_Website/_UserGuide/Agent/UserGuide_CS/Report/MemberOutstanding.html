会员未结束交易

定义:

这份报告显示会员的总投注额于尚在进行中的注单及代理基于占成数的共享数额。


图2.1

注:

  • 投注额 = 100, 赔率 = 0.9 那么未完成交易 = 100
  • 投注额 = 100, 赔率 = - 0.9 那么未完成交易 = 90
  • 代理占成 = 未完成交易 * 代理占成数
用词注解:
  • 未完成交易: 合计所有尚在进行中的注单.
  • 代理占成: 代理基于占成数所得到的金额.
如何理解报告:

例如, member02投注200于赛事FC Koln -vs- Schalke, 赔率 = -0.87, 此投注状况为 "进行中" 和代理目前拥有30%占成数。

  • 未完成交易 = 200 * 0.87 = 174
  • 代理占成 = 174 * 30% = 52.2

要深入了解这些进行中的注单, 点击未完成交易数额查看投注历史(进行中)。 在进行中的注单页面, 您也能够查看

  • 投注历史
  • 每日账目

3. 每日账目:

  • 这份报告总结了所有的交易, 然后投入每日记录在案。每日记录余额为总结当前日期的最新余额。

在上图中, member01至10/04/2008 星期六的输赢总额将被总结并显示为10/05/2008星期日的期初余额.

用词注解:

  • Bal-Opening balance: 总计所有输赢及转账交易至到期初余额日期之前。
  • Bet-Betting statement: 总计有输赢的所有投注。
  • Tra-To customer: 代理作出的转账数额。
  • Bet-Outstanding Bet: 总计所有尚在进行中的投注。
  • Credit/debit: 输赢数额或转账数额。
  • Commission: 会员佣金。

如何理解报告:

上方的每日账目显示以下细节:

  • 星期日 10/05/2008, 为期初余额日, member01至到该日的总余额为 269.40
  • 星期五 10/10/2008, member01投注 100, 赢额 39, 得到 0.1 佣金额结果他/她的总余额 = 269.4 + 39 + 0.1= 308.5
  • 星期六 10/11/2008, member01投注 1,000, 输额 104.5, 得到 5.2 佣金额结果他她的总余额 = 308.5 -104.5 + 5.2 = 209.2
  • 星期二 10/14/2008, agent01转账 100 到member01, 所以他/她的余额 = 209.2 - 100 = 109.2
  • 星期三 10/15/2008, member01投注 100 而这些投注仍在进行中, 所以他/她的最新余额为 109.2
