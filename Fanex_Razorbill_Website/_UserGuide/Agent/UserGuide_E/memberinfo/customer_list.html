Customer List

Definition:

This is a list of members belong to the agent; of course, agent can update his/her member through member list or view the member daily statement.


Customer List

Term definition:

  • Status: member status (Open, Closed or Suspended).
  • Group: group which member belong to, different groups then different commission rates.
  • A comm 1: Agent discount for bet types: Handicap, Over/Under, Odd/Even.
  • A comm 2: Agent discount for bet type: 1x2.
  • A comm 3: Agent disccount for other bet types
  • P comm 1: Player discount for bet types: Handicap, Over/Under, Odd/Even.
  • P comm 2: Player discount for bet type: 1x2.
  • P comm3: Player discount for other bet types.

How to edit member information?

  • We can edit single member information or multiple members information with the following details: information, status, commission, bet settings and position taking.
  • For Sportbook Bet setting and Position Taking, we can set the value for each sport type or use the setting of Soccer/Basketball then apply to other sport types.
Edit Sportbook
    Edit single member information
    • Click on “Status” of member under status column to edit that member information, then member editing page will be opened, refers to New Member guide line to understand the details in this page.


Edit Single Customer

    Edit multiple member information
    • Tick on each member then click "edit icon" to edit multiple members information, then multiple member editing page will be opened, refers to New Member guide line to understand the details in this page. Remember that all members will have the same setting.To edit all members, use function "Check All".

How to view member daily statement?

Click on member username, then member daily statement page will be opened.


Daily Statement

  • Term definition:
    • BAL-OPENING BALANCE: total balance included all transfer amounts.
    • BET-Betting statement: win/lost amount on settled tickets.
    • BET-Outstanding Bet: total turnover on running/waiting tickets.
    • TRA-To Customer: transfer amount which has been made.
