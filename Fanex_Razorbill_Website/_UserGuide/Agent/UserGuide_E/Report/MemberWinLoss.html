Member Win/Loss

Definition:

This report shows all necessary information which helps agent aware of his win/loss amount per member in a period of time.

When we first launch Member Win Loss, the page will display numbers of match for each sport type including running match, settled match for today and yesterday (figure 1.1).

  • Entered: number of settled matches.
  • Non-entered: number of running matches.

figure 1.1

Specify the period of time at From date and To date to view Win/Loss report then click "Submit" button (figure 1.2).


figure 1.2

Term definition:

  • Turnover: the total amount of all stakes.
  • Member Win/Loss: win/loss amount of members.
  • Member Comm: an amount of money that members received from the agent as commission.
  • Member Total: total win/loss amount of members including commission.
  • Agent Win/Loss: win/loss amount of agent based on his position taking.
  • Agent Comm: an amount of money that agent received from upline as commission after deducting member commission.
  • Agent total: total amount that agent wins or loses including commission.
  • Company: the amount of money that agent will pay to or receive from upline.
How to understand the report:

In this report, agent takes 30% position taking share, 0.2% as agent discount and player discount is 0.2%. To calculate the win/loss, we need to click on the username (ex: member01) then Member Bet List page will be opened and shows us the detail of each bet as below.


figure 1.3

And now, an example will show you how to calculate the member win/loss for 1 ticket. In reality, we have to calculate win/loss and commission on each ticket to get the grand total of agent, member win/loss.

Let's calculate win/loss number of agent on member01 as shown in figure 1.2, in this case member01 has only 1 bet ticket.

  • Member Win/Loss = stake * odds = 100 * 0.66 = 66
  • Member commission = stake * Player discount = 100 * 0.2% = 0.2
  • Member Total = Member Win/Loss + Member commission = 66 + 0.2 = 66.2
  • Agent Win/Loss = - Member Win/Loss * Agent  PT= - 66 * 30% =-19.8
  • Agent commission = (stake * Agent discount * upline PT) - Member commission = [100 * 0.2% * (100 % - 30%)] – 0.2 = 0.14 – 0.2 = -0.06
  • Agent Total = Agent Win/Loss + Agent commission = -19.8 – 0.06 = -19.86
  • Company = - (Member Total + Agent Total) = -(66.2 – 19.86) = -46.34
