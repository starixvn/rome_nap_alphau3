Member Outstanding

Definition:

This report shows the total amount of member stake on running tickets and the shared amount of agent based on the position taking.


figure 2.1

Note:

  • Stake = 100, odds = 0.9 then Outstanding = 100
  • Stake = 100, odds = - 0.9 then Outstanding = 90
  • Agent position = Outstanding * Agent PT
Term definition:
  • Outstanding: sum of all stakes of running tickets.
  • Agent position: shared amount of agent based on the position taking.
How to understand the report:

For example, member02 placed a bet 200 on match FC Koln -vs- Schalke, odds = -0.87, this bet has status “running” and Agent currently occupies 30% position taking.

  • Outstanding = 200 * 0.87 = 174
  • Agent Position = 174 * 30% = 52.2

In the figure above, all win/loss amounts of member01 up to Saturday 10/04/2008 will be summed up and displays in this report as Opening balance on Sunday 10/05/2008.

TERM DEFINITION

  • Bal-Opening balance: sum amount of all winlost and transfer transactions up to the day before Opening balance date.
  • Bet-Betting statement: sum of all bets which have win/loss amount.
  • Tra-To customer: transfer amount made by agent.
  • Bet-Outstanding Bet: sum of all bets which have status as running.
  • Credit/debit: win/loss amount or transfer amount.
  • Commission: member commission.

HOW TO UNDERSTAND THE REPORT

Daily statement above shows the following details:

  • Sunday 10/05/2008, is the opening balance date and total balance up to that day of member01 was 269.40
  • Friday 10/10/2008, member01 bet 100, won 39, got 0.1 as commission and therefore his/her balance = 269.4 + 39 + 0.1= 308.5
  • Saturday 10/11/2008, member01 bet 1,000, lost 104.5, got 5.2 as commission so his/her balance = 308.5 -104.5 + 5.2 = 209.2
  • Tuesday 10/14/2008, agent01 transfer 100 to member01 then his/her balance= 209.2 - 100 = 109.2
  • Wednesday 10/15/2008, member01 bet 100 and these bets are still running so his/her latest balance is still 109.2
