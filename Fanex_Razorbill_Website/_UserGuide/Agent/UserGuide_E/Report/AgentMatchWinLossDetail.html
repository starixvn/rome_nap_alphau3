Match Win/Loss Detail

Definition:

This report displays the total member and agent win/loss detail for each match. You can select desired date and then just click on "Submit" button.


figure 4.1
Term definition:
  • TurnOver: total amount of member stakes
  • Bet type: bet type which has been selected to place bet.
  • Member Win/Loss: win/loss amount of members.
  • Member Comm: amount of money that members received from the agent as commission.
  • Member Total: total member win/loss amount including commission.
  • Agent Win/Loss: amount of money that agent wins/loses based on position taking.
  • Agent Comm: amount of money that agent receives from or pays to upline as commission after deducting member commission.
  • Agent total: total agent wins/loss amount including commission.
  • Company Comm: the commission amount that agent received from upline.
  • CompanyTotal: total amount that agent pays to or receives from upline.
How to understand the report:

In this report, member placed a bet with stake=100, odds=0.66, member discount=0.2%, agent discount =0.2%, agent position taking 30% and member won the bet. Let’s take match FC Tokyo -vs- Jubilo Iwata as an example to understand how to calculate the report: (figure 4.1, first row).

  • Member Win/Loss = stake * odds = 100 * 0.66 = 66.
  • Member commission = stake * player discount = 100 * 0.2% = 0.2
  • Member total = Member Win/Loss + Member commission = 66 + 0.2 = 66.2
  • Agent Win/Loss = - ( Member Win/loss  * Agent PT ) = 66 * 30% = -19.8
  • Agent comm = (stake *(stake * Agent discount* upline PT) - Member commission = (100 * 0.2%*( 100% - 30%)) - 0.2 = -0.06
  • Agent Total = Agent Win/Loss + Agent commission = - 19.8 - 0.06 = -19.86
  • Company comm = stake * Agent discount * upline Position Taking = 100 * 0.2% * (1-30%) = 0.14
  • Company total = -(Member Total + Agent Total) = -(66.2 - 19.86) = -46.34

Note: This is just a simple example to guide you how to calculate win/loss amount for 1 bet. In reality, 1 match might contain many bets so we have to calculate win/loss and commission for each bet then sum up to have total amount of all win/loss.
