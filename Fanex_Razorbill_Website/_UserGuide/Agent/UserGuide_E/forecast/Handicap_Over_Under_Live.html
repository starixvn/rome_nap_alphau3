Handicap/Over Under/ Live

  • In this example, member placed a bet on Everton -vs- Liverpool, stake = 100, odds=0.6, agent PT = 50%, bettype = HDP, member choice: Everton 0.5
    • If (Home score - Away score) >= 0 then member will win
      --> agent will lose: 100 * 0.6 * 50% = 30
    • If (Home score - Away score) < 0 then member will lose
      --> agent will win: 100 * 50% = 50
