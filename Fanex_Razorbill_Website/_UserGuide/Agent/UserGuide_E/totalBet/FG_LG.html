First Goal/Last Goal

Definition:

Show agent's win/loss amount for First Goal, Last Goal bet type.


First Goal/Last Goal

  • On AUSTRALIA A-LEAGUE, match Queensland Roar -vs- Perth Glory:
    • If First Goal is made by Queensland Roar, agent will win 32.5
    • If Last Goal is made by Perth Glory, agent will lose 55
    • Others case, agent will win 100
  • On ENGLAND FA CUP, match Hartle United-vs-West Ham United:
    • If First Goal is made by Hartle United, agent will lose 145
    • Other cases, agent win 100
