賽果

定義:

只需按照以下步驟, 此報告將顯示每場比賽的賽果:

  • 指定所需的日期
  • 選擇運動類別
  • 選擇相應的聯賽

這有包括幾種狀態: 關閉, 進行中, 已完場, 退款(全場), 退款(上半場)及在賽事結束後狀態將會從一開始的"進行中"變成"已完場"
