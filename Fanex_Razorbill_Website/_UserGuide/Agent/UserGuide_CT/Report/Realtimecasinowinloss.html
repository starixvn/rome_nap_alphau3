娛樂城即時輸贏

定義:

娛樂城即時輸贏為不斷更新代理關於遊戲結束後的娛樂城輸贏,佣金的報告

 

圖: 會員即時輸贏

用詞註解:

  • 遊戲類型: 遊戲種類。目前只有百家樂, 賭場德州撲克, 骰寶, 21點和超級輪盤
  • 開始餘額: 遊戲結束前的原始餘額
  • 結束餘額: 遊戲結束後的綜合餘額
  • 投注額: 投注金額
  • 佣金: 佣金數額
  • 成績: 遊戲結果
  • 代理%: 代理佔成數

如何理解報告:

參照會員輸贏報告以獲取信息。此外, 包含在此報告的娛樂城遊戲歷史頁面將對您顯示每一場娛樂城遊戲細節。


圖: 賭場遊戲歷史

 

  • 此報告只包含娛樂城輸贏數額。
  • 要查看娛樂城遊戲的圖片成績, 勾取"賽果含圖片"複選框
