投注類別輸贏

定義:

這份報告顯示會員總投注額, 會員輸贏, 代理輸贏, 及代理在一段時間內根據公司在每場投注的輸贏必須支付予或從上線處接收到的數額


圖 5.1

用詞註解:

  • 投注額: 會員根據投注類別的總投注額
  • 會員輸贏: 會員根據投注類別的輸贏數額
  • 會員佣金: 會員從代理處得到的佣金數額
  • 會員總和: 會員包括佣金的總輸贏數額
  • 代理輸贏: 代理基於佔成數的輸贏數額
  • 代理佣金: 扣除會員佣金後, 代理收到或支付予上線的佣金數額
  • 代理總和: 代理包括佣金的總輸贏數額
  • 公司: 代理需支付予或從上線處接收到的總數額
如何理解報告:

從上圖中, 我們可以告訴大家會員投注 1,500 於讓球盤及大小盤的投注類別,共贏得 384, 代理輸 115.2及可從上線處得到 268.80 以補償其支付於會員的數額。
