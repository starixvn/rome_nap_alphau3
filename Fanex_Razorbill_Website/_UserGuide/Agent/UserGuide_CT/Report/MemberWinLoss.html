會員輸贏

定義:

這份報告顯示所有必要的信息, 以幫助代理清楚了解個別會員在特定日期裡的輸贏

當我們開啟 "會員輸贏", 頁面會顯示今日與昨日的個別運動類型的賽事場數, 當中包括 "成績已輸入場數" 和 "成績還沒輸入場數" (圖1.1)

  • 成绩还没输入场数: 赛事还未输入成绩之总数
  • 成績還沒輸入場數: 賽事還未輸入成績之總數

在 "從" 和 "到" 選擇日期, 然後點擊 "提交" 以查閱指定日期的輸贏報告 (圖1.2)


圖 1.2

用詞註解:

  • 投注額: 總投注數額
  • 會員輸贏: 會員輸贏的數額
  • 會員佣金: 會員從代理處得到的佣金數額
  • 會員總和: 會員包括佣金的總輸贏數額
  • 代理輸贏: 代理基於佔成數的輸贏數額
  • 代理佣金: 扣除會員佣金後, 代理收到或支付予上線的佣金數額
  • 代理總和: 代理包括佣金的總輸贏數額
  • 公司: 代理需支付予或從上線處接收到的總數額
如何理解報告:

在這份報告中, 代理獲取佔成數 30%, 代理折扣為 0.2%及會員折扣為 0.2%。為計算輸贏, 我們必須點擊用戶名 (例如: member01), 進入會員投注列表頁, 並顯示每次投注之細節


圖 1.3

現在, 例子將告訴您如何計算會員該投注單的輸贏。在現實中, 我們必須計算每張投注單的輸贏及佣金, 才能獲得代理、會員的輸贏總計

如圖1.2所示, 讓我們根據member01計算代理的輸贏, 假設member01只有一張投注單

  • 會員輸贏 = 投注額 * 賠率 = 100 * 0.66 = 66
  • 會員佣金 = 投注額 * 會員折扣 =  100 * 0.2% = 0.2
  • 會員總和 = 會員輸贏 + 會員佣金 = 66 + 0.2 = 66.2
  • 代理輸贏 = 會員輸贏 * 代理佔成 = - 66 * 30% =-19.8
  • 代理佣金 = (投注額* 代理折扣* 上線佔成) - 會員佣金
                 = [100 * 0.2% * (100 % - 30%)] – 0.2 = 0.14 – 0.2 = -0.06
  • 代理總和 = 代理輸贏 + 代理佣金 = -19.8 – 0.06 = -19.86
  • 公司 = - (會員總和 + 代理總和) = -(66.2 – 19.86) = -46.34
