會員未結束交易

定義:

這份報告顯示會員的總投注額於尚在進行中的注單及代理基於佔成數的共享數額


圖 2.1

注:

  • 投注額 = 100, 賠率 = 0.9 那麼未完成交易 = 100
  • 投注額 = 100, 賠率 = - 0.9 那麼未完成交易 = 90
  • 代理佔成 = 未完成交易 * 代理佔成數
用詞註解:
  • 未完成交易: 合計所有尚在進行中的注單
  • 代理佔成: 代理基於佔成數所得到的金額
如何理解報告:

例如, member02投注 200 於賽事 FC Koln -vs- Schalke, 賠率 = -0.87, 此投注狀況為 "進行中" 和代理目前擁有 30% 佔成數

  • 未完成交易 = 200 * 0.87 = 174
  • 代理佔成 = 174 * 30% = 52.2

要深入了解這些進行中的注單, 點擊未完成交易數額查看投注歷史(進行中).在進行中的注單頁面, 您也能夠查看

  • 投注歷史
  • 每日賬目

3. 每日賬目:

  • 這份報告總結了所有的交易, 然後投入每日記錄在案。每日記錄餘額為總結當前日期的最新余額

圖2.4

在上圖中, member01至 10/04/2008 星期六的輸贏總額將被總結並顯示為 10/05/2008 星期日的期初餘額

用詞註解:

  • Bal-Opening balance: 總計所有輸贏及轉賬交易至到期初餘額日期之前
  • Bet-Betting statement: 總計有輸贏的所有投注
  • Tra-To customer: 代理作出的轉賬數額
  • Bet-Outstanding Bet: 總計所有尚在進行中的投注
  • Credit/debit: 輸贏數額或轉賬數額
  • Commission: 會員佣金

如何理解報告:

上方的每日賬目顯示以下細節:

  • 星期日 10/05/2008, 為期初餘額日, member01至到該日的總餘額為 269.40
  • 星期五 10/10/2008, member01 投注 100, 贏額 39, 得到 0.1 佣金額結果他/她的總餘額 = 269.4 + 39 + 0.1 = 308.5
  • 星期六 10/11/2008, member01投注1,000, 輸額 104.5, 得到 5.2 佣金額結果他她的總餘額 = 308.5 - 104.5 + 5.2 = 209.2
  • 星期二 10/14/2008, agent01轉賬 100 到member01, 所以他/她的餘額 = 209.2 - 100 = 109.2
  • 星期三 10/15/2008, member01投注 100 而這些投注仍在進行中, 所以他/她的最新余額為 109.2
