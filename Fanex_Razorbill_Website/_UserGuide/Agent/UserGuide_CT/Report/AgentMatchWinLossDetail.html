輸贏報告資料

定義:

這份報告顯示所有會員和代理每場賽事的輸贏資料。您可以選擇所需的日期然後點擊提交按鈕


圖 4.1
用詞註解:
  • 投注額: 總投注數額
  • 投注類別: 被選定進行投注的投注類別
  • 會員輸贏: 會員輸贏的數額
  • 會員佣金: 會員從代理處得到的佣金數額
  • 會員總和: 會員包括佣金的總輸贏數額
  • 代理輸贏: 代理基於佔成數的輸贏數額
  • 代理佣金: 扣除會員佣金後, 代理收到或支付予上線的佣金數額
  • 代理總和: 代理包括佣金的總輸贏數額
  • 公司佣金: 代理從上線處得到的佣金數額
  • 公司總和: 代理需支付予或從上線處接收到的總數額
如何理解報告:

在這份報告中, 會員投注額 = 100, 賠率 = 0.66, 會員折扣 = 0.2%, 代理折扣 =0.2%, 代理佔成數 = 30% 及會員贏得此投注。 根據賽事 FC Tokyo -vs- Jubilo Iwata 作為例子以理解如何計算此報告: (圖4.1中, 第一行)。

  • 會員輸贏 = 投注額 * 賠率 = 100 * 0.66 = 66.
  • 會員佣金 = 投注額 * 會員折扣 = 100 * 0.2% = 0.2
  • 會員總和 = 會員輸贏 + 會員佣金 = 66 + 0.2 = 66.2
  • 代理輸贏 = - (會員輸贏* 代理佔成數) = -(66 * 30%) = -19.8
  • 代理佣金 = (投注額 * (投注額 * 代理折扣 * 上線佔成數) - 會員佣金 = (100 * 0.2%*( 100% - 30%)) - 0.2 = -0.06
  • 代理總和 = 代理輸贏 + 代理佣金 = - 19.8 - 0.06 = -19.86
  • 公司佣金 = 投注額 * 代理折扣 * 上線佔成數 = 100 * 0.2% * (1-30%) = 0.14
  • 公司總和 = - (會員總和 + 代理總和) = -(66.2 - 19.86) = -46.34

注. 這只是一個簡單的例子來指導您如何計算單一投注的輸贏數額。在現實中, 一場賽事可能包含許多投注所以我們必須計算每個投注的輸贏及佣金, 然後總計所有輸贏的數額
