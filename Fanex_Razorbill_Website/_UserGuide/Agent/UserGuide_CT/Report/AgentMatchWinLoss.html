球賽輸贏

定義:

這是代理於每場特定的比賽 (只是單項投注類別) 輸贏數額的總計。用戶可選擇所需的日期以查看賽事的輸贏。

注: 對於混合過關投注類別, 連接到輸贏報告資料


圖 3.1
用詞註解:
  • 賽事: 被選擇投注的賽事
  • 投注類別: 被選擇投注的投注類別
  • 佣金: 代理扣除會員佣金後, 從上線處得到的佣金
  • 佔成數: 總計代理予該場賽事的輸贏數額基於他/她的佔成數
  • 總和: 總計代理輸贏數額包括佣金
如何理解報告:

在上圖中, 以FC Koln -vs- Schalke 04這場賽事為例子, 要理解如何計算代理在此賽事的輸贏, 我們點擊賽事名稱以開啟會員投注歷史頁面


圖 3.2

在此註單, member02投注 200, 會員折扣 = 0.2%, 賠率 = -0.87, 他贏得該投注單, 代理佔成 = 30% 及代理從上線處接收 0.2% 佣金。 根據此信息我們可計算代理在該場比賽的輸贏 (圖3.1, 第一行)

  • 佣金: 代理佣金- 會員佣金 = 200*0.2%*(1-30%)-200*0.2% = -0.12
  • 佔成數: 若會員贏, 則佔成數: - (投注額*代理佔成數) 或會員輸, 則(投注額*代理佔成數) = -200*30% = -60
  • 總和: 佣金 + 佔成數 = -0.12 -60 = -60.12

注: 一場比賽可能會有很多投注, 因此我們必須使用上述公式計算代理佣金及代理每次投注的份額的總數
