Casino Position Taking

Definition:

Show the initial Casino position taking Master takes when creating an agent and the maximum position taking that Agent can take on member.

If you want to see the actual position taking that master/agent take on member on each game type, click on the Agent username (figure 1.2).

How to edit position taking:

Click on member's username to edit position taking.
