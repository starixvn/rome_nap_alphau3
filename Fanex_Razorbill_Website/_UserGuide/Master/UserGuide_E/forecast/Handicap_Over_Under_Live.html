Show master's win/loss amount for Handicap/Over Under/Live bet type (figure 1.1).

Note:

  • If Odds < 0
    - If player wins then odds = 1.
    - If player loses then odds = |current odds|.
  • If Odds > 0
    - If player wins then odds = current odds.
    - If player loses then odds = 1.
In this example, member placed a bet on URAWA RED DIAMOND -vs- HIROSHIMA SANFRECCE, stake = 120, odds=0.86, master PT = 30%, agent PT = 40%, bettype = HDP, member choice: Hiroshima Sanfrecce 0.5.
  • If (Home score - Away score) > 0 then member will lose.
    --> master will win: 120 * 30% = 36.
  • If (Home score - Away score) <= 0 then member will win.
    --> master will lose: 120 * 0.86 * 30% = 31.
