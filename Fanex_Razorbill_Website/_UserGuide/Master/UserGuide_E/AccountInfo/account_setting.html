Account Setting

Definition:

This is where master can view and edit setting for downlines.


Setting

Term definition:

  • Allow Outright: indicates whether or not this account is allowed Outright betting.
  • Enable SA Tote: indicates whether or not this account is enabled Horse Racing SA Tote.
  • Enable UK Tote: indicates whether or not this account is enabled Horse Racing UK Tote.
  • Enable Finance: indicates whether or not this account is enabled Finance betting.
  • Enable Casino: indicates whether or not this account is enabled Casino games.

Feature support:

  • Edit Info: allows user to edit First Name, Last Name, Phone, Mobile Phone, Email, Fax.
  • Bet Setting: allows user to edit Bet setting. Refers to Bet Setting guideline to understand the details in this page.
  • Commission allows user to edit downline commission. Refers to Commission Setting guideline to understand the details.
  • Reset Password: a place to change password for downlines. Password must be at least 6 characters including at least 2 letters and 2 digits.
  • Edit Sportsbook: allows user to edit Sportsbook setting of downline, refers to Edit Sportsbook setting guideline to understand the details.
  • Edit HR: allows user to edit Horse Racing setting of downline, refers to Edit Horse Racing setting guideline to understand the details.
  • Edit Finance: allows user to edit Finance setting of downline, refers to Edit Finance setting guideline to understand the details.
  • Edit Casino: allows user to edit Casino setting of downline, refers to Edit Casino setting guideline to understand the details.
  • SB's Min PT: allows user to edit Min Sportsbook Position Taking, refers to Min Sportsbook Position Taking setting guideline to understand the details.
  • HR's Min PT: allows user to edit Horse Racing Position Taking, refers to Min Horse Racing Position Taking setting guideline to understand the details.
  • FI's Min PT: allows user to edit Min Finance Position Taking, refers to Min Finance Position Taking setting guideline to understand the details.
  • Transfer: change Transfer condition. Refers to Transfer condition guideline to understand the details
  • Clear All Credit: allows user to clear all credit of downline.
Note:

Master can also view login log which includes: Created Date, Last Login, Last Transaction, Login IP and Online List, just click on Login, Online List tab.
