Agent Outstanding

Definition:

This report show the total amount of member stakes on running tickets and the shared amount of master,agent based on the position taking (figure 1.1).


figure 1.1

Term definition:

  • Outstanding: Sum of all member stakes of running tickets.
  • Master Position: Shared amount of master based on the position taking.
  • Casino Transer: Amount of money that member transfer to Casino.
  • Casino Outstanding: Un-finished balance of Casino running game. (This value only appears when member transfers back money to IBC).

You can click on Agent username to view Member Outstanding and Agent share amount on running tickets (figure 1.2).


figure 1.2

Term definition:
  • Outstanding: Sum of all member stakes of running tickets.
  • Agent Position: Shared amount of agent based on the position taking.
How to understand the report:

In this report, member1 placed a bet on match Brisbane Olympic -vs- Redlands United, stake = 100, odds = 0.98, status =Running, Master position taking = 30% and Agent position taking = 40%. Moreover, this member also transfer 1,000 from Sportsbook to Casino to play game and he leave an un-finished game with stake = 50.

We have result as displayed in figure 1.1 and figure 1.2:

  • Member outstanding = stake * odds = 100 * 1 = 100.
  • Agent Position = Outstanding * Agent PT = 100 * 40% = 40.
  • Master Position = Outstanding * Master PT = 100 * 30% = 30.
  • Casino Outstanding = 50.

figure 1.6

In the figure above, all win/loss amounts of Member1 up to Friday 07/09/2010 will be summed up and displays in this report as Opening balance on Saturday 07/10/2010.

TERM DEFINITION

  • Bal-Opening balance: sum amount of all winlost and transfer transactions up to the day before Opening balance date.
  • Bet-Betting statement: sum of all bets which have win/loss amount.
  • Traa-From Customer: transfer amount for payment purposes.
  • Bet-Outstanding Bet: sum of all bets which have status as running.
  • Credit/debit: win/loss amount or transfer amount.
  • Commission: Agent commission.

HOW TO UNDERSTAND THE REPORT

Daily statement above shows the following details:

  • Saturday 07/10/2010, is the opening balance date and total balance up to that day of Member1 was -874.81.
  • Saturday 07/10/2010, Member1 bet 200, won 4, got 0.3 as commission and therefore his/her balance = -874.81 + 4 + 0.3= -870.51.
  • Sunday 07/11/2010, Member1 bet 100, won 300, got 0 as commission so his/her balance = -870.51 + 300 + 0 = -570.51.
  • Tuesday 07/13/2010, bet 200, lose 8, got 0.15 as commission so his/her balance = -570.51 - 8 + 0.15 = -578.36.
  • Saturday 07/17/2010, bet 100, won 42.5, got 0.05 as commission so his/her balance = -578.36 + 42.5 + 0.05 = -535.81.
  • Wednesday 07/21/2010, Member1 bet 200 and these bets are still running so his/her latest balance is still -535.81.
  • Wednesday 07/21/2010, agent01 transfer 535.81 to member1 then his/her balance = -535.81 + 535.81 = 0.
