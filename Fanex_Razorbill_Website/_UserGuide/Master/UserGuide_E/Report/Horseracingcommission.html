Horse Racing Commission

Definition:

This is the Horse Racing commision report, in which a detail earning for each bet type( Win, Place and Win/Place ) will be listed out. This report figure out master's earning or losing amount on each agent per bet type (figure 1.1).


figure 1.1

Term definition:

  • Win: The amount of money that master receives from up-line as commission after deducting agent commission per Win bet type.
  • Place: The amount of money that master receives from up-line as commission after deducting agent commission per Place bet type.
  • Win Place: The amount of money that master receives from up-line as commission after deducting agent commission per Win Place bet type.
  • Total: The total amount of money that master receives from up-line as commission after deducting agent commission.

Click on Agent username to view agent's earning or losing amount on each member per bet type (figure 1.2).


figure 1.2

Term definition:

  • Win: The amount of money that agent receives from up-line as commission after deducting member commission per Win bet type.
  • Place: The amount of money that agent receives from up-line as commission after deducting member commission per Place bet type.
  • Win Place: The amount of money that agent receives from up-line as commission after deducting member commission per Win Place bet type.
  • Total: The total amount of money that agent receives from up-line as commission after deducting member commission.

How to understand the report:

To calculate the commission, we need to click on the username (ex: member1) then Member Bet List page will be opened and shows us the detail of each bet as below (figure 1.3):


figure 1.3

And now, an example will show you how to calculate commission. Let's calculate commission amount of master01, agent1 as shown in figure 1.1 and figure 1.2.

Figure 1.2:

  • Win = Stake * Agent discount * (1 - Agent PT) - Stake * Member discount = 20 * 0.5% * (1 - 20%) - 20 * 0.4% = 0
  • Place = Stake * Agent discount * (1 - Agent PT) - Stake * Member discount = 20 * 0.5% * (1 - 10%) - 20 * 0.4% = 0.01
  • Win Place = 0
  • Total = Win + Place + Win Place= 0 + 0.01 + 0 = 0.01

Figure 1.1:

  • Win = Stake * Master discount * [1 - (Master PT + Agent PT)] - Stake * Agent discount * (1 - Agent PT) = 20 * 0.8% * [1 - (20% + 20%)] - 20 * 0.5% * (1 - 20%) = 0.02
  • Place = Stake * Master discount * [1 - (Master PT + Agent PT)] - Stake * Agent discount * (1 - Agent PT) = 20*0.8% * [1 - (20% + 10%)] - 20 * 0.5% * (1 - 10%) = 0.02
  • Win Place = 0
  • Total = Win + Place + Win Place = 0.02 + 0.02 + 0= 0.04
