Cancelled Bets

Definition:

This report helps agent keep track of bets which are cancelled or rejected by system during the last 3 days (figure 1.1).


figure 1.1

The report classifies all rejected or cancelled bets by each member, just click on the drop down list box to select the member then the page will display all cancelled bets placed by that member.

  • Void: the bet was accepted but finally was deleted by system administrator.
  • Rejected: the bet was rejected by operator at the time to place bet.
