Real Time Casino Win Loss

Definition:

Real time casino win loss is a report which keeps master updated about casino win/loss amount,commission right after a game is settled.


figure: 1.1

Term definition:

  • Turnover: The total betting amount on Casino games.
  • Rolling Turnover: The total betting amount on Casino games exclude tie games.
  • Member Win/Loss: Member win/loss amount.
  • Member Comm: The amount of money that member receives from the agent as commission.
  • Member Total: Total member win/loss amount including commission.
  • Agent Win/Loss: Agent win/loss amount based on his position taking.
  • Agent Comm: The amount of money that agent receives from upline as commission after deducting member commission.
  • Agent Total: Total agent win/loss amount including commission.
  • Master Win/Loss: Master win/loss amount based on position taking.
  • Master Comm: The amount of money that master receives from up-line as commission after deducting agent commission.
  • Master Total: Total master win/loss amount including commission.
  • Company: The amount of money that master will pay to or receive from up-line.

Term definition:

  • Game Type: Type of Game.
  • Game Group: The group that game belongs to.
  • Start Balance: Initial balance before the game is settled.
  • End Balance: Overal balance after the game is settled.
  • Bet: Betting amount.
  • Stake = Bet amount - Tie amount.
  • Win/Loss: Win/Loss amount
  • Rolling commission: Commission amount.
  • Results: Game result.
  • MA%: Master position taking.
  • AG%: Agent position taking.
  • Session ID: a unique number used to identify a member that has accessed into Casino.

How to understand the report:

The report is sorted by GameID in descending order (figure 1.3). Let's calculate win/loss number of master1, agent01 on member01 as shown in figure 1.1 and figure 1.2. In this report, member01 accessed into casino 2 times to play game.

  • Session ID= 1256908: member01 played a Blackjack game, bet amount=10, member discount = 0.6%, master position taking = 60%, master discount = 0.8% , agent position taking = 10%, agent discount = 0.6% and member loses the bet.
       Start Balance = 100.
       Stake = Bet = 10.
       Member Win/Loss = -Stake = -10.
       Member Comm = Rolling Comm = Stake * Member discount = 10 * 0.6% = 0.06.
       Member Total = Member Win/Loss + Member Comm = -10 + 0.06 = -9.94.
       End Balance = Start Balance + Member Win/Loss + Member Comm = 100 - 10 + 0.06 = 90.06.
       Agent Win/Loss = Stake * Agent PT = 10 * 10% = 1.
       Agent Comm = Stake * Agent discount * (1 - Agent PT) - Member Comm = 10 * 0.6% * (1 - 10%) - 0.06 = -0.01.
       Agent Total = Agent Win/Loss + Agent Comm = 1 - 0.01 = 0.99.
       Master Win/Loss = Stake * Master PT = 10 * 60% = 6.
       Master Comm = Stake * Master discount * [1 - (Master PT + Agent PT)] - Stake * Agent discount * (1 - Agent PT) = 10 * 0.8% * [1 - (60% + 10%)] - 10 * 0.6% * (1 - 10%) = -0.03.
       Master Total = Master Win/Loss + Master Comm = 6 - 0.03 = 5.97.

  • Second session: member01 placed bet 5 on game type Blackjack, member discount = 0.6%, master position taking = 60%, master discount = 0.8% , agent position taking = 10%, agent discount = 0.6% and this is the tie game.
       Start Balance = End Balance in betting 1 = 90.06.
       Stake = 0.
       Member Win/Loss = 0.
       Member Comm = Rolling Comm = 0.
       Member Total = 0.
       End Balance = Start Balance + Member Win/Loss + Member Comm = 90.06 + 0 + 0 = 90.06.
       Agent Win/Loss = 0.
       Agent Comm = 0.
       Agent Total = 0.
       Master Win/Loss = 0.
       Master Comm = 0.
       Master Total = 0.
