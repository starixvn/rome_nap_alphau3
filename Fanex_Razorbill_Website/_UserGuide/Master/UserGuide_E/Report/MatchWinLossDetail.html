Match Win/Loss Detail

Definition:

This report displays the total member, agent, master win/loss detail for each match. You can select desired date and then click Submit button.


figure 1.1
Term definition:
  • Bet Type: Bet type which has been selected to place bet.
  • Turnover: The total amount of member stakes.
  • Gross Comm: Maximum amount of money that master might receive from the up-line as commission.
  • Member Win/Loss: Win/loss amount of member.
  • Member Comm: The amount of money that member receive from the agent as commission.
  • Member Total: Total win/loss amount of member including commission.
  • Agent Win/Loss: Win/loss amount of agent based on his position taking.
  • Agent Comm: The amount of money that master gives to agent as commission.
  • Agent Total: The total amount of money that master receives from or pays to agent.
  • Master Win/Loss: Win/loss amount of master based on master’s position taking.
  • Master Comm: The amount of money that master receive from upline as commission after deducting agent commission.
  • Master Total: Total amount that master wins or loses including commission.
  • Company Comm: Master commission received from up-line.
  • Company Total: The amount of money that master will pay to or receive from up-line.
How to understand the report:

In this report, member bet 120, odds= 0.86, member discount=0.15%, agent discount =0.15%, agent position taking 40%, master discount =0.2%, master position taking = 30%. Let’s take match “Pirin Blagoevgrad (N)-vs-Lokomotiv Plovdiv” as an example to understand how to calculate the report. In this ticket, member loses:

Note:

  • If Odds < 0
    - If player wins then odds = 1.
    - If player loses then odds = |current odds|.
  • If Odds > 0
    - If player wins then odds = current odds.
    - If player loses then odds = 1.
  • If bet type is Correct Score, 1x2, Total Goal, FT/HT, Outright, Mix parlay, FG/LG then odds = current odds -1.
  • This is just a simple example to show you how to calculate win/loss amount for 1 bet.In reality, 1 match might contains many bet so we have to calculate win/loss and commission for each bet then sum up to have total amount of all win/loss.
  • Turnover = stake = 120.
  • Gross Comm = stake * Master discount = 120 * 0.2% = 0.24.
  • Member Win/Loss = -stake * odds = -120 * 1 = -120.
  • Member Comm = stake * Member discount = 120 * 0.15% = 0.18.
  • Member Total = Member Win/Loss + Member Comm = -120 + 0.18 = -119.82.
  • Agent Win/Loss = stake * Agent PT = 120 * 40% = 48.
  • Agent Comm = stake * Agent discount * (1 - Agent PT) = 120 * 0.15% * (1 - 40%) = 0.11.
  • Agent Total = Member Win/Loss + Agent Win/Loss + Agent Comm = -120 + 48 + 0.11 = -71.89.
  • Master Win/Loss = stake * Mater PT = 120 * 30% = 36.
  • Master Comm = stake * Master discount * [1 - (Master PT + Agent PT)] - Agent Comm = 120 * 0.2% * [1 - (30% + 40%)] - 0.11 = -0.04.
  • Master Total = Master Win/Loss + Master Comm = 36 - 0.04 = 35.96.
  • Company Comm = stake * Master discount * [1 - (Master PT + Agent PT)] = 120 * 0.2% * [1 - (30% + 40%)] = 0.07.
  • Company Total = -(Member Win/Loss + Agent Win/Loss + Master Win/Loss + Company Comm) = -(-120 + 48 + 36 + 0.07) = 35.93.
