Result

Definition:

This report displays the result of each match, just follow these steps:

  • Specify the desired date.
  • Select Sport type.
  • Select league accordingly.

There’re some available statuses: Closed, Running, Completed, Refund, Refund FT, Refund HT and the status of a match will be changed from “Running” at the beginning of the match to “Completed” at the end of the match.

1. SOCCER


figure 1.1
  • Term definition:
    • Kick off time: Match starting time.
    • First half score: Score of the 1st Half of the match.
    • Final score: Final score of the match.
    • Status: Match status.
