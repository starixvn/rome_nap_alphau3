Agent Win/Loss

Definition:

This report shows all necessary information which helps master aware of his win/loss amount per member in a period of time.

When we first launch Agent Win Loss, the page will display numbers of match for each sport type including running match, settled match for today and yesterday (figure 1.1).

  • Entered: number of settled matches.
  • Non-entered: number of running matches.

figure 1.1

Note: If you want to see the report data more than 3 months, please click on View History Report (figure 1.2). In this report, you can see the data of last 18 months.


figure 1.2

Specify the period of time at From date and To date to view Win/Loss report then click "Submit" button (figure 1.3).


figure 1.3

Term definition:

  • Member Turnover: The total amount of all member’s stake under each agent.
  • Gross Comm: Maximum amount of money that might master receives from the up-line as commission.
  • Agent Total: The amount of money that master receives from or pays to agent.
  • Master Win/Loss: Win/loss amount of master based on master’s position taking.
  • Master Comm: The amount of money that master receives from up-line as commission after deducting agent commission.
  • Master Total: Total amount that master wins or loses including commission.
  • Company: The amount of money that master will pay to or receive from up-line.

Click on Agent username to view Member Win Loss report under each particular agent (figure 1.4).

  • Company: The amount of money that master will pay to or receive from agent.
How to understand the report:

From figure 1.3 and figure 1.4, we can puzzle out the winloss report as follows:

  • Member1 lose the bet (stake=120, member commission=0.18), therefore his total winloss amount including commission = -119.82.
  • Agent1 earning amount based on position taking, commision = 47.93, but he got 119.82 from member1, so he has to pay master1 71.89 .
  • Master1 earning amount based on position taking, commission = 35.96, but he got 71.89 from agent1, so he has to pay upline 35.93.

To understand the whole win/loss report, we need to drill down to member level, then click on the member's username (ex: member1) then Member Bet List page will be opened and shows us the detail of each bet as below (figure 1.5):

And now, an example will show you how to calculate the member win/loss for 1 ticket. In reality, we have to calculate win/loss and commission on each ticket to get the grand total of master, agent, member win/loss.


figure 1.5

Let's calculate win/loss amount of master01 on member1 and the amount of money that master has to deal with his agent1 as shown in figure 1.3 and figure 1.4. In this example, member1 placed a bet on match Pirin Blagoevgrad (N)-vs-Lokomotiv Plovdiv, stake = 120, odds = 0.86, player discount = 0.15%, master position taking = 30%, master discount = 0.2%, agent position taking = 40%, agent discount = 0.15% and member lose this bet.

Figure 1.4:  This is member, agent winloss amount.

  • Turnover = member stake = 120.
  • Gross Comm = stake * Agent discount = 120 * 0.15% = 0.18.
  • Member Win/Loss = -stake * odds= -120 * 1 = -120.
  • Member Comm = stake * Player discount = 120 * 0.15% = 0.18.
  • Member Total = Member Win/Loss + Member Comm = -120 + 0.18 = -119.82.
  • Agent Win/Loss = stake * odds * Agent PT = 120 * 1 * 40% = 48.
  • Agent Comm = stake * Agent discount * (1 – Agent PT) – Member Comm = 120 * 0.15% * (1 – 0.4) – 0.18 = -0.07.
  • Agent Total = Agent Win/Loss + Agent Comm = 48 – 0.07 = 47.93.
  • Company = -(Member Total + Agent Total) = -(-119.82 + 47.93) = 71.89.

Figure 1.3:  This is master winloss and the amount of money he needs to deal with upline/downline (pay or receive).

  • Member Turnover = stake = 120.
  • Gross Comm = stake * Master discount = 120 * 0.2% = 0.24.
  • Agent Total = -Company in figure 1.3 = -71.89.
  • Master Win/Loss = stake * odds * Master PT = 120 * 1 * 30% = 36.
  • Master Comm = stake * [Master discount*[1 – (Master PT + Agent PT)] – Agent discount*(1 – Agent PT)] = 120 * [0.2%*[1 – (30% + 40%)] – 0.15%*(1 – 40%)] = -0.04.
  • Master Total = Master Win/Loss + Master Comm = 36 - 0.04 = 35.96.
  • Company = -(Agent Total + Master Total) = -(-71.89 + 35.96) = 35.93.

Note:

  • If Odds < 0
    - If player wins then odds = 1.
    - If player loses then odds = |current odds|.
  • If Odds > 0
    - If player wins then odds = current odds.
    - If player loses then odds = 1.
  • If bet type is Correct Score, 1x2, Total Goal, FT/HT, Outright, Mix parlay, FG/LG then odds = current odds -1.
