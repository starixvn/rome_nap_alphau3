赛果

定义:

只需按照以下步骤, 此报告将显示每场比赛的赛果:

  • 指定所需的日期。
  • 选择运动类别。
  • 选择相应的联赛。

这有包括几种状态: 关闭, 进行中, 已完场, 退款(全场), 退款(上半场) 及在赛事结束后状态将会 从一开始的 "进行中" 变成 "已完场"。

图 1.1

    • 开赛时间: 赛事开始的时间。
    • 上半场比分: 赛事的上半场比分。
    • 最后比分: 赛事的最后比分。
    • 状态: 赛事的状态。
