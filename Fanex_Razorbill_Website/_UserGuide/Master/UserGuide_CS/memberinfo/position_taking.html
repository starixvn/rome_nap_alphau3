占成数%

定义:

显示总代理创建代理时取得的总代理原始占成数, 和代理从会员处可得到的最高占城数。


图 1.1

如果您要查看基于个别运动类型及投注类型, 总代理/代理从每个会员处取得的实际占成数, 点击代理用户名 (图1.2)。


图 1.2

如何编辑占成数:

点击会员用户名以修改占成数。


图 1.3

注:

  • 总代理占成 + 代理占成 <= 上线设定的总代理最高占成。
  • 总代理占成 + 代理占成 >= 上线设定的总代理最低占成。
  • 总代理可以设置个别投注类型对于个别运动类型或使用足球/篮球的设置应用到其他运动类别, 投注类别。
  • 对于非滚球投注:
    • 从亚洲盘复制然后应用于大小盘, 上半场亚洲盘, 上半场大小盘, 单双投注类别。
    • 从1x2复制然后应用于波胆, 总进球, 混合过关, 优胜冠军投注类别。
  • 对于滚球投注: 从亚洲盘复制然后应用于大小盘, 上半场亚洲盘, 上半场大小盘, 单双投注类别。
