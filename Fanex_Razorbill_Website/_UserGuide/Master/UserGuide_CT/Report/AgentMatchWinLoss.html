Match Win/Loss

Definition:

This is a total agent win/loss amount on each particular match (single bet type only). User can choose desired date to view the match win/loss.

Note: For Mix Parlay bet type, go to Match Win Loss detail


figure 3.1
Term definition:
  • Match: match which has been selected to place bet.
  • Bet type: bet type which has been selected to place bet.
  • Comm: the money agent received from upline as commission after deducting member commission.
  • Position Taking: total Agent Win/Loss amount on that match based on his/her position taking.
  • Total: total Agent Win/Loss amount on that match including commission.
How to understand the report:

In figure above, take match FC Koln -vs- Schalke 04 as an example, to understand how to calculate win/loss for agent on this match, we click on match name to open Member Bet List page.


figure 3.2

On this ticket, member02 placed a bet 200, member discount = 0.2%, odds = -087, he won the bet, agent PT = 30% and agent received 0.2% as commission percentage from upline. With this information we can calculate the match win loss for agent (figure 3.1, fist row).

  • Comm = agent comm – member comm = 200*0.2%*(1-30%)-200*0.2% = -0.12
  • Position taking = -(stake*Agent PT) if member won or (stake*Agent PT) if member lost = -200*30% = -60
  • Total = comm + position taking = -0.12 -60 = -60.12

Note: one match might contain many bets therefore we have to use the formula above to calculate agent commission and agent own's share on each bet then sum up all amounts.
