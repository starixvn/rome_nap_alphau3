Security Code FAQS

1. What is Security Code?

It is 6 numeric digits [0-9] and you will be asked to enter this security code when you perform important updates such as resetting password, updating account settings, etc.

2. How to setup security code?

Input the security code and confirm it, follow the notes below.
Note:
. Security code must be 6 numeric digits [0-9] and contains at least 2 different digits.
. Security code must not a ‘Forward Run or ‘Backward Run’ number ( A ‘Forward Run’ number is an integer whose digits are all in consecutive, ascending order, left to right; whereas a ‘Backward Run’ number is an interger whose digits are all in consecutive, descending order, left to right. For example: 123456, 456789, 764321, etc.. are not allowed.)

3. Does the security code expire?

It is not expired but you should change it periodically.

4. What functions require a security code?

· Change/reset password.
· Create/Update accounts or sub-accounts.
· Reopen/un-suspend accounts.
· Allocate credit.
· Reset downline password.
· Change/Reset downline security code.
· Transfer.

5. What happens if I entered wrong security code?

It will require you to re-enter security code again, be noted that your account will be closed after entering the wrong security code over 5 times. Please contact your upline or CSD in this case.

6. What if I have forgotten my security code?

Contact your upline or CSD to reset your security code.

7. How do I change my security code?

At the Home page, go to Security tab, then choose Security Code link, then change your security code.

8. I'm an Agent and was requested to provide Security Code for my Member, how can I do?

Please go to Member Information - Customer List, choose a Member, click on Edit icon, then Security Code, a page will be displayed to allow you to reset Security Code for your member. You can also go to Account Info, search for the Member, then go to Setting - Reset Security Code.

9. I saw an announcement said that I should contact my upline to get Security Code but my upline does not have it yet. How can I do?

You have to wait your upline to set their security code for you.
